# Социальный режим «Лис»

## Принцип

Сервер всегда остаётся единственным источником истины. Лис, интерфейс и будущая ИИ-модель предлагают действия, но не могут напрямую менять очередь, раскрывать секрет или повышать показатели отношений.

## Дерево раунда

```text
question
├─ free_text ──> await_acknowledgement ──> next_question
└─ player_picker ──> await_player_choice
   ├─ answer ──> record_relationship ──> next_question
   └─ skip ──> next_question
```

Следующие узлы будут добавляться только после появления серверной комнаты:

```text
public_prompt
└─ private_prompt
   ├─ answer ──> encrypted_secret_vault ──> anonymous_followup
   ├─ decline ──> cooldown_question
   └─ timeout ──> next_player
```

## Направленный граф

Каждая связь хранится отдельно: отношение `player-a → player-b` не меняет `player-b → player-a`.

```json
{
  "trust": 0.5,
  "attraction": 0.1,
  "jealousy": 0,
  "protection": 0.25,
  "conflict": 0,
  "curiosity": 0.25,
  "confidence": 0,
  "evidence": []
}
```

Числа меняются только после явного ответа. Пропуск ничего не уменьшает.

## Видимость будущей комнаты

- `public`: идентификатор вопроса, цель, фаза и таймер.
- `target-only`: полный личный вопрос и варианты ответа.
- `server-only`: исходный текст секрета, автор и политика раскрытия.
- `anonymous`: только проверенная перефразировка без автора и исходного текста.

## Контракт будущего ИИ

Модель получает псевдонимы, агрегированные показатели и разрешённые события. Сырые секреты по умолчанию не передаются. Ответ модели должен соответствовать строгой схеме:

```json
{
  "action": "ask_private_followup",
  "targetPlayerId": "player-id",
  "question": "Текст вопроса",
  "answerType": "player_picker",
  "visibility": "target_only",
  "metric": "trust",
  "revealPolicy": "anonymous_paraphrase"
}
```

Сервер проверяет возрастной режим, согласие, допустимую цель, фазу раунда и политику раскрытия. Невалидное решение заменяется вопросом из локальной базы.

## Следующий технический этап

Нужны серверная база и Realtime-канал для разных телефонов. Клиенту потребуется только публичный ключ; секреты сервера и ключ ИИ никогда не попадают в браузер.
